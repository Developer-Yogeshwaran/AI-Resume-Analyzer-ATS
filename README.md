# AI Resume Analyzer (ATS)

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT) 
[![Python Version](https://img.shields.io/badge/Java-SpringBoot-blue)](https://spring.io/projects/spring-boot)

**AI Resume Analyzer (ATS)** is a powerful tool that analyzes resumes, matches them with job descriptions, and helps recruiters and job seekers optimize resumes for Applicant Tracking Systems (ATS).

## Features

- ✅ Upload resumes in various formats (PDF, DOCX)  
- ✅ Automated parsing and analysis of skills, experience, and education  
- ✅ Matches resumes with job descriptions  
- ✅ Provides insights to optimize resumes for ATS  
- ✅ Clean and modular backend architecture
